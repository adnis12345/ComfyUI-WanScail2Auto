This project is secondary encapsulated based on the official Wan2.1 nodes WanSCAILToVideo and SamplerCustom, implementing a fully automatic computation pipeline for long-video face replacement and motion transfer.
SCAIL-2 is currently one of the best open-source models for video character replacement and motion migration. However, its original workflow is extremely cumbersome for long-video processing, requiring manual frame counting, manual video segmentation, multi-workflow splicing, and repeated parameter assignment, resulting in high usage costs and poor batch processing efficiency.
To solve these pain points, this project refactors and optimizes the native logic of SCAIL-2, specially tailored for long-video scenarios. It completely eliminates redundant manual operations including frame calculation, video segmentation, and repeated workflow configuration.
The core node WanAutoSegmentSingleNode can intelligently split long videos into segments of 81 frames (the optimal inference specification for the model) automatically, performing segmented generation and seamless splicing. It enables one-click, efficient and simplified SCAIL-2 character replacement and motion transfer for long videos.
